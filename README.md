A 30-second vertical GTA 6 fan edit, cut from official Rockstar Trailer 2 footage with ffmpeg in the session that built this entry. It hooks on the cargo-plane jump, runs through Leonida — night chase, highway signs, helicopter and jet-ski action, dusk skyline — and pitches make.fun on screen: viewers can make money on make.fun by making cool clips with AI. The clip itself is the entry; its views on YouTube decide the places. `VIDEO.json` names the public YouTube Short, and `main.ts` copies it to the output directory for the gate to read.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
